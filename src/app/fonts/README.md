# Fusion Pixel

The bundled font is the 12 px proportional Simplified Chinese variant of [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font), official release **2026.11.10**, distributed under SIL Open Font License 1.1. It includes Latin and Chinese glyphs and is loaded locally through `next/font/local`; visitors do not contact a font provider. The original binary is unmodified.

Source archive: `fusion-pixel-font-12px-proportional-otf.woff2-v2026.11.10.zip` from the project's GitHub release. `OFL.txt` and all upstream licence notices included in that archive are retained alongside the font.
