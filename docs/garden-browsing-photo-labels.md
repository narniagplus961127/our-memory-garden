# Garden browsing and photo organization

`/garden` automatically applies title/slug search after a 400 ms typing pause, and page-date year/category selections immediately. A parent category includes descendants. Filter choices come only from public, non-trashed, non-homepage pages and their category ancestors, including for signed-in administrators. Undated pages appear under All years. Changing or clearing filters starts at page one; pagination and browser navigation preserve the chosen filters. The existing date/category indexes and 24-card pagination remain in use; these queries never fetch image bytes or editor content. See [automatic filtering and pixel details](automatic-filters-pixel-details.md) for focus, Chinese composition and artwork behavior.

Photo details has an Organize tab for the shared photo name and comma-separated labels. Names allow 200 characters; up to 20 labels allow 40 characters each. Labels are trimmed and deduplicated without case sensitivity. Library, single-photo and Photo Grid searches match labels as well as names. Labels remain administrator metadata and are not included in public photo-grid data.

Migration `0026-photo-library-metadata.sql` adds labels and a separate photo metadata version. Saves require an administrator and matching origin. Conflicting edits keep the draft and offer an explicit reload; retrying an already completed save does not write again. Renaming changes neither photo IDs, storage keys, image URLs, fingerprints, image bytes, saved page content nor visibility. Existing originals are never read or rewritten. Independent manual backups include photo names and labels as snapshot metadata.

The original versioned SVG fence sits above the footer's green top border, with centered text below. The visitor menu is a full-screen popup with centered original nine-slice wooden planks and smaller indented planks for descendants. Its close header stays visible while the list scrolls independently, including when submenus expand. Both assets are decorative, cached for a year and contain no external references. Future artwork changes must use a new versioned filename. Menu labels remain real text, the separate disclosure arrow remains available and existing click/keyboard navigation is preserved. Reduced-motion preferences disable the entrance animation.

Photo Grid blocks share a wooden quest-board surface in the editor and on the website. Photos sit on decorative torn-paper mounts with small pixel pins. The masonry measurement includes each mount's top, side and bottom insets, preserving original photo proportions and preventing overlap. Columns, gaps, corner radius, ordering, Load more, animation and the zoom/swipe viewer retain their existing controls. These surfaces use CSS and the existing responsive thumbnail sources; no image copies, additional downloads or saved page-content migration are needed.

Local verification uses isolated PostgreSQL, auth and S3-compatible storage. Desktop/mobile browser journeys cover filters, pagination, private-choice exclusion, photo editing, stale-edit recovery, search and responsive artwork. Service checks cover authentication/origin, input limits, unchanged media identity/bytes, private labels and backup snapshot preservation. Hosted authenticated browser behavior is separate from the anonymous release smoke checks.
