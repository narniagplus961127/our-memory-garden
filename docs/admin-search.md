# Category and template search

Categories and Templates filter their existing lightweight list data by a trimmed, case-insensitive query. Category search includes the full category path and keeps ancestors visible for context. Matching a parent path includes its descendants. Clearing search restores the existing manual sequence; filtering never saves a new order.

Drag handles are disabled while a nonempty query is active. Clear search before rearranging a list so a partial view cannot overwrite the complete order. Edit, view and other row actions continue to target the same stable IDs.

The page content import popup also searches template names. An already selected template remains in the selector when it does not match a new query, with a message explaining that it was kept. Search/clear/cancel do not replace content; the existing review and explicit replacement action remain required, including current-source validation and History. Search adds no photo or page-content downloads.
