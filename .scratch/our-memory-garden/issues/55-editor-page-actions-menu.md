# 55 — Group page editor actions under a gear

Status: resolved

Open View page, History, Save as template, and Delete page from the top-right gear on desktop and mobile. Keep page metadata in the sidebar and the Pages link in the header. View page opens a new tab, and History opens the current page's version history. Save as template and Delete page keep their confirmations and return focus to the gear on cancellation. Deletion waits for saved page changes and remains unavailable for the homepage.
