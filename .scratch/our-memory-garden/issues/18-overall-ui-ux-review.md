# 18 — Review overall website UI and UX

Status: resolved

## Request

Review the overall public website and administration layout for useful UI/UX improvements.

## Answer

The current garden theme and fluid layout are sound. Prioritize mobile admin-menu dismissal and finding pages as the collection grows, then consistent primary actions, settings wayfinding, keyboard shortcuts to content, optional reading width and a site-gutter preset. No wider website redesign was implemented during this review.

The browser confirmed a mobile menu remaining open after navigating to Settings. The live homepage's unusual left padding comes from its own saved 9 px block setting, not an unintended shell gutter change. The page-list scale check used 594 synthetic local pages; it is not a production usage/performance claim.

Full findings, recommendation order, review boundaries and evidence: [UI/UX review](../../../docs/ui-ux-review-2026-11-03.md). The later toolbar reference and approved font/line-height additions are implemented under ticket 19.
