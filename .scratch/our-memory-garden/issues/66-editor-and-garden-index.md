# 66 — Photo selection, mobile Text alignment, category ancestry and garden index

Status: resolved

- In the Photo Grid photo picker, Shift-click selects the range from the last clicked photo. Ctrl-click or Command-click toggles a photo. Ctrl+A or Command+A selects the currently loaded search results while a photo has focus. Plain clicks and taps keep toggling individual photos. The existing add-batch limit applies.
- Text block settings include a Mobile section. Centre applies to the whole block at the site's mobile breakpoint, including rich text. The default follows desktop alignment.
- Checking a subcategory in Page settings selects and saves every ancestor. Unchecking a parent clears its selected descendants. Unchecking a child keeps its parent selected.
- The public `/garden` index uses the category page card layout and lists public pages by page date. It excludes the current homepage, private pages and trashed pages in every session.
