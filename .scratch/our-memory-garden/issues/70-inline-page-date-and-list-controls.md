# 70 — Insert page dates in Text blocks

Status: resolved

- Insert Page date from the inline Text toolbar in the current cursor position. The default format displays as `07 JULY 2024`. Short English and Chinese formats are also available.
- Use the date from Page settings. Show a placeholder in the visual editor when it is unset and omit the date in the rendered page. Template and page-content JSON workflows keep the field, so it displays the destination page’s date.
- Show a magnifier in the Pages list search input and keep search and sort accessible without visible labels or placeholder copy.
