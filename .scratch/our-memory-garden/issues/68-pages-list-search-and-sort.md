# 68 — Search and sort the Pages list

Status: resolved

- Search titles and page URLs in the Pages list, even when a sort order is active.
- Sort by name, created date, page date or updated date in either direction. Put undated pages last in both page-date sorts.
- Keep saved manual order as the default. Dragging is available in the unfiltered Manual order view, and changing views does not write a new order.
