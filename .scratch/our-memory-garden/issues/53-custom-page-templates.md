# 53 — Create and edit page templates

Status: resolved

Add a private Templates area for named layouts. Administrators can create a blank template or confirm a copy of a saved page from Page settings. Copies preserve the layout, styles and text and replace image photos with placeholders. Legacy galleries become a single Image placeholder. Section background photos are cleared. Use the same visual editor to change a template, then choose it when creating a new private page. Source pages, templates and derived pages are independent. Include saved templates in garden exports.

Desktop and mobile browser tests verified cancel without creating a copy, photo placeholders from an uploaded image, visual edits, starting a private page from a saved template, and building a blank template. The existing visual editor link workflow also passed on both viewport sizes.
