# 63 — Add an icon divider and public footer

Status: resolved

Add a Divider block inside sections and columns. It renders two balanced lines around a garden logo, star, heart or custom emoji. The garden logo is selected on insertion. The custom field accepts one emoji or decorative symbol and stays available after switching back to Custom emoji. An empty custom field shows a plain line.

The block uses the existing spacing, appearance, autosave and page JSON settings.

Show a centered Our Memory Garden footer in small white text on dark green across the public site.
