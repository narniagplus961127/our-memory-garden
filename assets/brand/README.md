# Our Memory Garden brand assets

Direction: Sunlit Garden. Warm parchment, forest ink, quiet botanical details.

- `garden-gate-mark.png`: transparent generated brand mark.
- `logo-horizontal.svg`: horizontal lockup with an embedded raster mark and editable Georgia text; this is a hybrid SVG, not a fully vector-traced mark.
- `logo-horizontal.png`: rendered horizontal lockup.
- `favicon.svg`: simplified vector arch and paired leaves, on parchment, for small browser icons.
- `favicon.ico`: 16, 32, and 64-pixel versions, with corresponding PNG files.

Use the logo at comfortable sizes. Use the simplified favicon where the full gate detail would be too small. Keep original uploaded memories separate from the generated garden photograph, which is sample design imagery only.

## Generation record

The mark and sample garden photo were generated with the built-in image-generation tool. The favicon was drawn as a simplified native vector counterpart and rendered with FigCraft. ICO packaging preserves the exported PNGs without image changes.

Mark prompt: “Create a polished single standalone brand symbol for Our Memory Garden, a personal botanical journal website for a couple. No text or letters. Deep warm forest green only, transparent background. A softly arched garden gate containing two botanical stems leaning toward one another, representing two people growing together. Four broad leaves, balanced negative space, strong strokes, compact square composition. No gradients, shadows, textures, mockups or background.”

Photo prompt: “A quietly beautiful cottage garden in soft late-afternoon sunlight, a narrow brick path, daisies and cosmos, terracotta herb pots, a slightly open wooden picket gate, lush plants and warm greens and creams with a few blush flowers. Authentic editorial analog photography, subtle imperfections, no people or text. Wide landscape composition for an edge-to-edge website sample image; not a real memory of the users.”
