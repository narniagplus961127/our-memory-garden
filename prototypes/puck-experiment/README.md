# Puck editor experiment

Throwaway design experiment for ticket 00. Uses sample content and browser local storage only. It is not production code and does not connect to Supabase.

Run from this folder: `npm run dev`, then open the printed localhost address. Use only sample data.

Try adding text, image placeholders, sections and columns; editing and moving them; switching canvas width; simulating a save failure, changing content, refreshing, and retrying. `Saved locally` is simulated and does not demonstrate server persistence or security. The experiment will be reviewed on desktop and mobile before the design is approved.
