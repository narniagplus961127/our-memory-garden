# Our Memory Garden

A shared botanical journal for two administrators, with public and private pages and a visual React page editor.

The project is in the design and editor-validation phase. Full application development has not started.

- Design: `Our Memory Garden.figcraft`
- Specification: `.scratch/our-memory-garden/spec.md`
- Tickets: `.scratch/our-memory-garden/issues/`
- Design review: `docs/design-spec-review.md`

The local Puck experiment is captured on branch `prototype/puck-editor`, under `prototypes/puck-experiment`. It uses sample data and local browser storage; it does not establish production authentication, security, or multi-user correctness.
